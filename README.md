# Portfolio Website

A modern, animated portfolio website built with React, Vite, and Tailwind CSS.

## Features

- ⚡ Fast performance with Vite
- 🎨 Smooth animations and transitions
- 📱 Fully responsive design
- 🎯 Modern UI with Tailwind CSS
- 🌟 Interactive hero section
- 📊 Projects showcase
- 💼 Experience timeline
- 🎓 Education section
- 🛠️ Skills display
- 📧 Contact section

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

The site will be available at `http://localhost:3000`

### Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Customization

Edit the content in `src/Portfolio.jsx` to personalize:

- Personal information
- Projects
- Experience
- Education
- Skills
- Social links

## Technologies Used

- React 18
- Vite
- Tailwind CSS
- Lucide React (icons)
